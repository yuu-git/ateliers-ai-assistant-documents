# 画面別 UI 仕様

実装後の配置・既存機能との対応・画像との差分・検証範囲は [UI 整理の実装状況](implementation-status.md) を参照する。

## 1. 通知・情報収集（最優先）

**参照:** `references/reference-notification-original.png`、`mockups/notification-layout.png`。

- 主画面は **情報源選択ペイン / 通知一覧 / 記事詳細** を役割別に配置する。
- 情報源選択は「すべて」＋実登録情報源。各件数を表示する場合は実データに基づく。
- 通知一覧の1行には記事名、情報源、日時、短い状態/概要。長い URL・内部 ID・モデル詳細は詳細側へ。
- 記事詳細は既存の Markdown レンダリング、リンク、保存先への導線を保持する。
- 手動巡回・Worker 状態・AI 一時停止状態を確認できる。**RSS 巡回と AI 要約の状態を混同しない。**
- 巡回履歴はタブ/切替表示。実行日時、成功/失敗、新規/重複/要約状況を閲覧できる。
- 記事の一括削除（最大100件・選択/全選択/解除/確認）、再取得時の扱い、巡回履歴保持を維持する。
- 初回・通知0件・Worker停止・API接続不可・要約待ち・巡回中の表示を用意する。
- Phase 3 の最新10件取得制限と重複判定は UI 改修で変更しない。

### 通知管理の追加仕様

- 初回取得日時をローカル日付で「今日／昨日／日付」にグループ化し、新しい順で表示する。
- 記事を明示的に開いたときだけ既読にし、初期選択・自動更新では既読にしない。未読だけ補助情報行の末尾へ赤系の「未読」を表示し、一覧に独立した既読ラベルを置かない。
- ナビゲーション・全体・情報源に DB 全表示対象通知の未読件数を表示する。要約待ちを含めない。
- 情報源と同じナビゲーション領域の「表示」から、すべて／未読のみ／ブックマークのみを常時切り替える。横長は情報源の上へ3項目と区切り線を配置し、中幅・狭幅は表示と情報源の選択欄を並べる。タグは展開領域から指定する。未読／ブックマーク／タグは DB 条件適用後100件、「すべて・タグなし」は全体最新100件内で情報源を絞る。
- 一覧は40×40の ☆／★ と、その下のゴミ箱を記事を開くボタンと分離する。ツールチップ・状態に応じたアクセシブル名と標準キーボード操作を備え、選択・既読化を発火させない。記事詳細の「記事の操作」に未読戻し・ブックマーク・手動タグをまとめる。
- 単体削除は既定で記事タイトル付きの確認を表示する。「次回以降は確認しない」は削除成功後だけ保存する。設定の「データと保存先」から再有効化でき、一括削除の確認は省略しない。[クイック操作の仕様・検証](../features/notification-quick-actions-implementation-status.md) を参照する。
- ブックマーク中の ★ は黄色、未登録の ☆ は標準色。ライト／ダークのテーマ別リソースを使い、ハイコントラストではシステム色を優先する。
- 一括削除は選択した記事数・ブックマーク付き件数・タグ付き件数を確認する。
- 詳細・範囲・検証結果は [通知管理の実装状況](../features/notification-management-implementation-status.md) を参照する。

## 2. 設定（高優先）

**参照:** `mockups/settings-layout.png`。

- 3カテゴリ（Worker／バックグラウンド AI／データと保存先）を視覚的に分ける。
- Worker の状態と起動・停止・再読込、自動起動の操作を維持。
- AI 一時停止はユーザーが見つけやすい位置に置く。自動ロード/アンロードの初期 OFF と注意文を維持。
- 保存済み設定と編集中設定、保存成功/失敗を区別する。保存前の変更を勝手に反映しない。
- 保存先の表示・コピー・エクスプローラー起動は維持。**保存先の変更機能は追加しない。**
- パスは選択・コピー可能にし、長いパスでもレイアウトが崩れない。
- Debug/Release 表示と環境別保存先を維持。

## 3. ナビゲーション（高優先）

- 機能／システム・管理の2分類。区切りと見出しを明確にする。
- 項目名・アイコン・選択状態を統一。
- 通知管理の追加改修により、Worker／AI 実状態と環境を共通フッターに表示する。展開すると設定画面と同じ開始・停止・AI即時操作を使える。狭幅は短縮表示とし、既存の状態ポーリングを共有する。

## 4. AI チャット／モデル管理／ログ（今回の変更は限定）

- **AI チャット:** Phase 1～2 の保存/再開、モデル選択、ストリーミング、中止、画像貼り付け、Markdown 表示を維持。今回はレイアウト全面改修をしない。
- **モデル管理:** モデル一覧、ロード状態、起動/停止操作を維持。空白が大きいことだけを理由に不要な UI を追加しない。
- **ログ:** 分類、レベル/期間/キーワード絞り込み、複数選択・コピー、詳細、ログフォルダーを開く機能を維持。今回は大幅改修をしない。

## 受け入れ条件

- [ ] ナビゲーションが2分類され、全ページに移動できる。
- [ ] Web 情報収集の初期画面で、通知閲覧が主役になっている。
- [ ] 情報源選択、通知閲覧、記事詳細、巡回履歴、情報源設定、手動巡回、一括削除が利用可能。
- [ ] 設定の3カテゴリが分かれ、従来の全設定・操作・注意文が残っている。
- [ ] Worker停止/AI停止/要約待ち/空データ時の表示が適切。
- [ ] UI 変更によって保存済みデータ、Worker API、ログ閲覧、チャット機能が壊れていない。
- [ ] Debug/Release ビルド、既存テスト、代表的な画面操作を確認した。
