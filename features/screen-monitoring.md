# 画面監視とゲームアシスタント

## 構想

Factorio、FF14 などのゲーム中に、一定間隔（例: 10秒）で画面を確認し、Vision 対応ローカル LLM が状況に応じて雑談・助言・コメントを生成する。初期段階ではコメントの妥当性を品質要件としない。

## 責務とプロセス

- 画面キャプチャは **ユーザーセッション側** の Windows プロセスで実行する。
- `Windows.Graphics.Capture` を第一候補とし、対象ウィンドウまたはディスプレイを選択する。
- Windows Service にデスクトップキャプチャを直接担当させない。
- WinUI 3 ウィンドウを閉じても監視を続けたい場合、ユーザーセッション常駐 Agent の独立を検討する。

## 処理

```text
監視 ON -> 対象選択 -> 定期キャプチャ
  -> 縮小・圧縮・変化判定
  -> Vision LLM 解析
  -> 過去の状況・発話と比較
  -> コメント必要性の判定
  -> 通知 / 音声（任意）
```

キャプチャ周期と推論周期、発話周期を別に管理する。ゲームは常時動くため単純な画像差分ではノイズが多く、ROI、閾値、クールダウン等を後から検討する。

## 検証項目

- ゲームのウィンドウ/フルスクリーンモードでキャプチャできるか。
- Ollama の Vision 対応モデルで画像入力が可能か。
- 画像サイズ、VRAM、推論時間、10秒周期の実現性。
- 画面に個人情報や他アプリが映る場合の除外・停止方法。
- ゲーム規約やアンチチートとの適合性。ゲーム内部への介入や入力自動化は初期スコープ外。

## 初期技術スパイク

UI 全体の完成を待たず、画面1枚をキャプチャし、Ollama に渡して説明文を得る最小実験を行う。成功後に定期処理やコメント履歴を追加する。
