# 音声・動画生成の連携

## 既存資産

- VoicePeak / VOICEVOX を利用してテキストから音声ファイルを生成する C# ライブラリが完成済み。
- VoicePeak または VOICEVOX + Marp + FFmpeg を組み合わせ、Markdown から音声付きスライド動画を生成する MCP ツールが完成済み。

これらは将来再利用する資産であり、初期チャット MVP に組み込む必要はない。

## 想定機能

1. AI の通知メッセージを音声生成し、自動再生する。
2. Markdown の内容を音声化し、通知・メッセージ欄の「音声として再生」操作から再生する。
3. Markdown の内容から音声付き解説動画を生成する（将来）。

## 設計方針

- **音声生成** と **音声再生** を別の責務として扱う。
- 生成機能は既存 C# ライブラリをサービス契約経由で呼び出す。
- 再生はユーザーセッション側で行う。Windows Service はスピーカーへの直接再生を担当しない。
- 動画生成は既存の C# ライブラリを直接呼べるならそれを優先し、独立したツール境界が必要なら MCP 経由を検討する。
- MCP はアプリケーション機能の唯一の実装場所とせず、外部に公開するアダプターの一つとして扱う。
- 長時間ジョブは実行状態、進捗、キャンセル、失敗、出力ファイルを管理する。

## 未決定

通知の自動再生条件、読み上げ対象、話者・音量・キュー制御、ファイル形式、音声の保存期間、動画生成をいつ UI に公開するか。既存ライブラリが GUI/ユーザーセッションを要求するかも実機検証する。
